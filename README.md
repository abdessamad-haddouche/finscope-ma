# FinScope MA

Plateforme web d'analyse financière automatisée pour les entreprises marocaines.

## Description

FinScope MA prend en entrée les états de synthèse comptables d'une entreprise (Bilan Comptable + CPC) et produit automatiquement une analyse financière complète et structurée, conforme aux normes du CGNC (Code Général de la Normalisation Comptable).

## Stack technique

- **Backend** : Node.js + TypeScript
- **Base de données** : PostgreSQL
- **Frontend** : React + TypeScript
- **Charts** : Chart.js
- **PDF** : Puppeteer
- **Excel parsing** : SheetJS (xlsx)
- **Auth** : JWT + bcrypt
- **Déploiement** : Railway
